# AGENTS.md

For any AI coding tool working in this repository.

## What this repository is

A public guide, with small scripts, for running AI privately on your own hardware. It recommends
tools; it does not vendor them.

## Rules

1. **Every version, license, price and default is dated and linked** to the page it was read from.
   A fact from memory is not a fact here. Mark anything you could not verify.
2. **State telemetry and network defaults next to every tool you recommend**, with how to turn
   them off, from the project's own docs or code. "Local" software that phones home by default is
   the most common way private data leaks.
3. **Check the license of weights separately from the code.** Model weights often carry a
   different license than the code that runs them.
4. **No private data in this repository.** Examples use synthetic data only: no real names,
   account numbers, addresses, hosts or keys.
5. **Regulatory notes are summaries of primary sources, not legal advice**, and say so.
6. American English, plain words, no em dashes.
